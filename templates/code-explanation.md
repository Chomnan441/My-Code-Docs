## 1. บทเรียนนี้เกี่ยวกับอะไร?

อธิบายหนึ่งย่อหน้าว่ากำลังอ่านส่วนใดของระบบ และทำไมส่วนนี้ถึงสำคัญกับผู้ใช้

ตัวอย่าง: บทเรียนนี้อธิบายฟังก์ชันที่รับข้อมูลจากฟอร์ม แล้วยังไม่ลงรายละเอียดทั้งไฟล์

## 2. ไฟล์ต้นฉบับและตำแหน่งโค้ด

| รายการ | ค่า |
| --- | --- |
| ไฟล์ | `path/to/file.go` |
| ช่วงบรรทัด | `[10–30]` |
| ภาษา | `[Go / TypeScript / SQL]` |

ถ้ามีหลายไฟล์ ให้เพิ่มแถว ไม่ต้องย้ายทั้งไฟล์มาวาง

## 3. โค้ดที่ต้องทำความเข้าใจ

วางเฉพาะช่วงที่กำลังอธิบาย ตัวอย่างด้านล่างเป็นตัวอย่างวิธีจัดรูปแบบ ไม่ใช่โค้ดจากโปรเจค

```go
func greet(name string) string {
    return "สวัสดี " + name
}
```

```ts
function greet(name: string): string {
  return `สวัสดี ${name}`
}
```

```json
{
  "name": "ตัวอย่าง",
  "status": "draft"
}
```

## 4. อธิบายการทำงานทีละขั้นตอน

1. ฟังก์ชันได้รับค่าอะไรเข้ามา
2. มีการตรวจค่าหรือแปลงค่าหรือไม่
3. เรียกฟังก์ชันอื่นหรือฐานข้อมูลตรงไหน
4. ส่งค่าอะไรกลับไป และใครเป็นคนนำไปใช้

## 5. คำศัพท์เทคนิคที่ควรรู้

| คำ | ความหมายในบทเรียนนี้ |
| --- | --- |
| `[handler]` | `[ฟังก์ชันที่รับคำขอแล้วเตรียมคำตอบ]` |

ถ้าคำนั้นมีประโยชน์กับบทอื่น ให้เพิ่มใน [คำศัพท์ที่ควรจำ](/notes/glossary) ด้วยหลังย้ายไฟล์นี้เข้า `docs/`

## 6. ตัวอย่างการทำงานจริง

เล่าหนึ่งสถานการณ์จากมุมผู้ใช้ แล้วโยงเข้ากับโค้ดด้านบน

ตัวอย่างการจัดรูปแบบเท่านั้น:

1. ผู้ใช้กรอกชื่อแล้วกดบันทึก
2. หน้าเว็บส่ง JSON ไปที่ Backend
3. ฟังก์ชันในข้อ 3 รับค่า `name` แล้วประกอบข้อความตอบกลับ

คำสั่ง SQL ด้านล่างก็เป็นแค่ตัวอย่างการเขียนบล็อกโค้ด:

```sql
SELECT title
FROM lesson
WHERE status = 'draft';
```

## 7. ความสัมพันธ์กับไฟล์อื่น

- ถูกเรียกจาก: `[path/to/caller.tsx]`
- เรียกต่อไปที่: `[path/to/repository.go]`
- ข้อมูลที่เกี่ยวข้อง: `[ชื่อตารางหรือชนิดข้อมูล ถ้ารู้จากโค้ด]`

```js
submitForm(values)
```

ถ้ายังไม่ตามหาไฟล์ที่เรียกมา ให้เขียนว่ายังไม่ได้ตรวจจากซอร์สโค้ด

## 9. คำถามทบทวนความเข้าใจ

1. ฟังก์ชันนี้รับค่าอะไร และคืนค่าอะไร
2. ถ้าข้อมูลที่ส่งมาว่าง โค้ดทำอะไร
3. ไฟล์ใดได้รับผลจากฟังก์ชันนี้ต่อ

ตอบสั้น ๆ ใต้คำถามหลังอ่านจบ ถ้าตอบไม่ได้ ให้กลับไปข้อ 4
