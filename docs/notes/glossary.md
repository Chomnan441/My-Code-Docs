# คำศัพท์ที่ควรจำ

คำด้านล่างเป็นคำทั่วไปที่ใช้ตอนอ่านเว็บที่มี Frontend, Backend และฐานข้อมูล ยังไม่ได้เก็บมาจากไฟล์ของ Job Application Tracker

| คำ | ความหมาย |
| --- | --- |
| Source Code | โค้ดต้นฉบับที่คนเขียนและอ่านได้ ก่อนถูกแปลงไปรัน |
| Frontend | ส่วนที่ทำงานบนเบราว์เซอร์และผู้ใช้มองเห็น |
| Backend | ส่วนที่ทำงานบนเซิร์ฟเวอร์ รับคำขอและทำงานกับข้อมูล |
| Component | ชิ้นส่วนของหน้าเว็บใน React ที่เขียนเป็นฟังก์ชัน |
| Props | ข้อมูลที่ส่งเข้าไปให้คอมโพเนนต์ |
| API | ช่องทางที่โปรแกรมใช้ขอหรือส่งข้อมูลหากัน |
| Endpoint | ที่อยู่ของ API หนึ่งเส้นทาง |
| JSON | รูปแบบข้อความสำหรับส่งข้อมูล เป็นคู่ของชื่อกับค่า |
| Handler | ฟังก์ชันที่รับคำขอหนึ่งแบบ แล้วเตรียมคำตอบ |
| Database | ที่เก็บข้อมูลอย่างเป็นตาราง เพื่อให้เปิดมาอ่านทีหลังได้ |
| SQL | ภาษาที่ใช้สั่งฐานข้อมูล |
| Repository | โปรเจคที่ Git เก็บประวัติการแก้ไข |
| Commit | การบันทึกการเปลี่ยนแปลงหนึ่งชุดใน Git |

เมื่อเจอคำใหม่จากซอร์สโค้ดของโปรเจค ให้เพิ่มแถวในตารางนี้ พร้อมความหมายจากบริบทของไฟล์นั้น
