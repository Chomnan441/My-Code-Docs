# พื้นฐานการเขียนโปรแกรม

ส่วนนี้สอนคำที่ใช้บ่อยเวลาเปิดซอร์สโค้ด บทเรียนเป็นความรู้ทั่วไป ไม่ได้อธิบายไฟล์ของ Job Application Tracker

อ่านเรื่องที่ตรงกับไฟล์ที่กำลังเปิดอยู่ แล้วค่อยกลับไปที่หน้าโปรเจค

## หัวข้อ

- [Go Basics](/fundamentals/go/) สำหรับไฟล์ `.go` และ Backend
- [React Basics](/fundamentals/react/) สำหรับคอมโพเนนต์บนหน้าเว็บ
- [REST API](/fundamentals/rest-api) สำหรับคำขอระหว่างหน้าเว็บกับเซิร์ฟเวอร์
- [SQL & PostgreSQL](/fundamentals/postgresql) สำหรับตารางและคำสั่งฐานข้อมูล
- [Git & GitHub](/fundamentals/git-github) สำหรับการบันทึกและส่งโค้ด

## ใช้พื้นฐานนี้ยังไง

เมื่อเจอบรรทัดที่อ่านไม่ออก ให้จดชื่อคำนั้นก่อน แล้วมาค้นใน [คำศัพท์ที่ควรจำ](/notes/glossary) หรือในหัวข้อด้านบน พอเข้าใจคำแล้วค่อยกลับไปอ่านไฟล์เดิมทีละฟังก์ชัน
