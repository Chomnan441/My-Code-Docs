# Git & GitHub

Git จำประวัติการแก้ไขไฟล์ในโปรเจค GitHub เป็นเว็บที่เก็บสำเนาของโปรเจคนั้น และใช้เผยแพร่เว็บเอกสารนี้ผ่าน GitHub Pages

## คำสามคำที่ใช้ทุกครั้ง

| คำ | ความหมาย |
| --- | --- |
| repository | โฟลเดอร์โปรเจคที่ Git ดูแลประวัติให้ |
| commit | การบันทึกชุดการเปลี่ยนแปลงหนึ่งครั้ง พร้อมข้อความอธิบาย |
| push | การส่ง commit จากเครื่องเราขึ้น GitHub |

เว็บนี้ใช้สาขา `main` เมื่อ push ขึ้นสาขานี้ GitHub Actions จะสร้างเว็บแล้วเผยแพร่ให้

## ลำดับที่ใช้บ่อย

ดูว่ามีไฟล์ใดเปลี่ยน แล้วเลือกไฟล์ที่จะบันทึก จากนั้นเขียน commit แล้วส่งขึ้น GitHub

```bash
git status
git add docs/notes/index.md
git commit -m "docs: add a learning note"
git push origin main
```

`git status` ยังไม่แก้ไฟล์ใด มันแค่แสดงรายการที่เปลี่ยน `git add` เลือกไฟล์ที่จะเข้า commit นี้
