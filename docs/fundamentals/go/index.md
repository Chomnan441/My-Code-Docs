# Go Basics

Go เป็นภาษาที่ใช้เขียน Backend ของ Job Application Tracker หน้านี้พาอ่านโครงไฟล์ Go แบบสั้น ๆ ตัวอย่างไม่ได้มาจากโปรเจค

## ไฟล์ Go เริ่มอย่างไร

ไฟล์ด้านล่างเป็นโปรแกรมเล็ก ๆ ที่พิมพ์ข้อความออกมา

```go
package main

import "fmt"

func main() {
    name := "My Code Docs"
    fmt.Println("สวัสดี", name)
}
```

อ่านทีละส่วนได้แบบนี้

1. `package main` บอกว่าไฟล์นี้อยู่ในแพ็กเกจชื่อ `main` โปรแกรมที่สั่งรันได้มักใช้แพ็กเกจนี้
2. `import "fmt"` หยิบเครื่องมือพิมพ์ข้อความมาใช้ ชื่อ `fmt` ย่อมาจาก format
3. `func main()` คือฟังก์ชันที่โปรแกรมเริ่มทำงาน ฟังก์ชันคือกลุ่มคำสั่งที่มีชื่อ
4. `name := "My Code Docs"` สร้างตัวแปรชื่อ `name` แล้วเก็บข้อความไว้ เครื่องหมาย `:=` ใช้ประกาศตัวแปรพร้อมกำหนดค่า
5. `fmt.Println` แสดงข้อความออกที่หน้าจอเทอร์มินัล

## คำที่เจอบ่อยในไฟล์ Go

| คำ | ความหมายคร่าว ๆ |
| --- | --- |
| `package` | กลุ่มของไฟล์ที่ทำงานร่วมกัน |
| `import` | การนำโค้ดจากแพ็กเกจอื่นมาใช้ |
| `func` | การประกาศฟังก์ชัน |
| `:=` | สร้างตัวแปรใหม่พร้อมใส่ค่า |
