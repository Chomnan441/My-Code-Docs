# โปรเจคทั้งหมด

หน้านี้รวบรวมโปรเจคที่ต้องการทำความเข้าใจจากซอร์สโค้ดจริง แต่ละโปรเจคจะถูกแบ่งเป็นภาพรวม, Frontend, Backend, Database และการทำงานร่วมกันของระบบ

ตอนนี้มีหนึ่งโปรเจค หน้าที่อยู่ในโปรเจคยังเป็นโครงบทเรียน เพราะยังไม่ได้วิเคราะห์ไฟล์ต้นฉบับในเว็บเอกสารนี้

## Job Application Tracker

เว็บสำหรับติดตามการสมัครงาน สร้างด้วย React, Go (Gin) และ PostgreSQL

สิ่งที่รู้ในตอนนี้มีแค่เทคโนโลยีที่ใช้ ยังไม่บันทึกรายชื่อไฟล์ ฟังก์ชัน หรือเส้นทางของข้อมูลจากซอร์สโค้ด

[เปิดภาพรวมโปรเจค](/projects/job-application-tracker/)

## วิธีอ่านโปรเจคในคลังนี้

1. เริ่มที่ภาพรวม เพื่อรู้ว่าโปรเจคใช้เทคโนโลยีอะไร
2. อ่านพื้นฐานที่เกี่ยวข้อง ถ้าเปิดไฟล์แล้วยังไม่รู้จักคำสั่งนั้น
3. กลับมาที่ Frontend, Backend หรือ Database เมื่อมีบันทึกจากซอร์สโค้ดแล้ว
4. ปิดท้ายด้วยหน้าการทำงานร่วมกันของระบบ เพื่อเห็นว่าแต่ละส่วนส่งงานต่อกันอย่างไร
