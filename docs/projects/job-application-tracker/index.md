# ภาพรวมโปรเจค

Job Application Tracker คือโปรเจคแรกในคลังนี้ หน้าที่ของหน้านี้คือเป็นแผนที่ก่อนลงไปอ่านโค้ดแต่ละส่วน

::: info โครงบทเรียน
ยังไม่ได้วิเคราะห์ซอร์สโค้ดของโปรเจคนี้ในเว็บเอกสาร ข้อความด้านล่างจึงบอกเฉพาะสิ่งที่รู้แล้ว คือชื่อโปรเจคและเทคโนโลยีที่ใช้ ยังไม่มีชื่อไฟล์ ฟังก์ชัน หรือพฤติกรรมของระบบจากโค้ดจริง
:::

## สิ่งที่รู้แล้ว

| หัวข้อ | รายละเอียด |
| --- | --- |
| ชื่อโปรเจค | Job Application Tracker |
| Frontend | React |
| Backend | Go ด้วยเฟรมเวิร์ก Gin |
| Database | PostgreSQL |

## ส่วนที่รอเติมจากซอร์สโค้ด

หลังเปิดโปรเจคจริง ให้กลับมาตอบคำถามเหล่านี้ในหน้าย่อย ไม่ต้องเดาคำตอบไว้ก่อน

- ผู้ใช้ทำอะไรบนหน้าเว็บได้บ้าง
- หน้าเว็บเรียก Backend ที่เส้นทางใด
- Backend อ่านหรือบันทึกข้อมูลตารางใด
- ข้อมูลหนึ่งรายการเดินทางจากฟอร์มไปถึงฐานข้อมูลอย่างไร
